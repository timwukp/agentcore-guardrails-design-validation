### 6. The module-collision guard caught a real hazard in the new F4 file

`lib/tests/test_module_name_collisions.py` failed: my `_load(path, name)` helper built its
`sys.modules` key from a **parameter**, so the guard could not read it statically. It reads every
by-path loader call to prove no two register the same name — `infra/04_gateway.py`'s stem is not a
legal identifier, so a collision would silently hand another script a different module under the same
key. Fixed by hoisting the key to a module-level constant (`GW_MODULE_NAME`) rather than adding an
`UNRESOLVABLE` exemption. Library suite back to **639 passed, 1 skipped**.
